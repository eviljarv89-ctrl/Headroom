Auto overclock

Finds the highest stable core offset, then memory offset, using Headroom's own CUDA stress test: every result is checked bit for bit against a stock run, and NVIDIA driver resets count as failures. Then a 3 minute combined soak, and a back-off of 30 MHz core / 250 MHz memory so games keep a margin. A crash or freeze mid-test is handled: the step is saved before it runs, so the next run skips it.

Research my hardware with Claude

Claude searches reviews and owner results for your exact parts (including your GPU's board partner and your motherboard's BIOS), then Headroom builds a profile from them with the source links. Only model names, versions and limits from the scan are sent. It takes a few minutes and uses your own Anthropic API key, so it's billed to your account; the log shows what it used.
